Edu C2C Marketplace is a comprehensive e-commerce marketplace built with PHP and MySQL, designed to facilitate seamless buying and selling of products online.

The platform features a complete admin dashboard for managing listings, users, and transactions, along with a user-friendly frontend for browsing products, viewing detailed listings, and making purchases. The project includes robust authentication, search functionality, and category-based filtering to enhance the user experience.

If you're interested in the implementation, check out the Repository on GitHub.
