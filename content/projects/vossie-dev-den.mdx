Vossie Dev Den is a static website for a student coding club. It gives students and visitors one place to learn about the club, discover upcoming activities, find coding resources, and connect with the community.

## A home for the coding club

The site introduces the club and links visitors to its main areas:

- **About:** the club's purpose, mission, and executive team
- **Events:** upcoming hackathons, workshops, and project showcases
- **Projects:** a space for club project cards and future case studies
- **Resources:** links to Codecademy, MDN Web Docs, and freeCodeCamp
- **Contact:** social and community contact links

## A retro coding theme

The interface uses a dark blue and black visual direction with a retro 3D grid background. A fixed header keeps the main navigation available, while responsive layouts support both desktop and mobile screens.

Shared site-wide styles keep the pages visually consistent, and a small JavaScript navigation menu provides the mobile experience.

## Static, page-based structure

Each major section is represented by its own HTML page. The project uses HTML5, CSS3, and vanilla JavaScript without an external framework or build tool.

```text
HTML pages
    |
Shared CSS styles
    |
Vanilla JavaScript navigation
```

The project can be opened directly in a browser or served locally with Python's built-in HTTP server.

## Current scope

The site currently uses sample event dates and team names. Its project cards are placeholders, and social links still need to be confirmed. Some external learning resources may also require an account or an internet connection.

Future work includes adding real project information and screenshots, confirming community links, improving contact options, and testing accessibility and browser compatibility.
