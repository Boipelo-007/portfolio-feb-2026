## Project pages in MDX

Project write-ups live in MDX and are compiled into individual routes with Contentlayer. The format keeps the content easy to revise while supporting code samples, lists, and technical details.

## Stack and delivery

The site is built with Next.js App Router, React, TypeScript, Tailwind CSS, Contentlayer, and Framer Motion. Upstash Redis stores page-view counts when configured, and Vercel Analytics tracks site traffic.

Project write-ups are authored in MDX and compiled into individual routes. The project detail pages are statically generated at build time, and the live portfolio is available at [boipelo.codes](https://boipelo.codes).
