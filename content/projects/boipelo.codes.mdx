## Overview

boipelo.codes is my personal portfolio website, designed to showcase my software development projects and technical skills. Built with modern web technologies, it features a clean, minimalist design with smooth animations and an intuitive user experience.

## Tech Stack

**Framework:**
- Next.js with TypeScript
- React for UI components
- Contentlayer for MDX content management

**Styling:**
- Tailwind CSS
- Custom particle animations
- Responsive, mobile-first design

**Deployment:**
- Vercel (optimized for Next.js)
- Analytics integration for tracking

## Features

- **Project Showcase** - Detailed project pages with descriptions, tech stacks, and live demos
- **MDX Support** - Rich content using MDX for project documentation
- **Dynamic Routing** - Seamless navigation with Next.js App Router
- **Analytics** - Track visitor engagement and page views
- **Particle Effects** - Interactive background animations
- **Dark Theme** - Modern, eye-friendly design

This portfolio serves as both a showcase of my work and a demonstration of my frontend development capabilities. The site is built with performance, accessibility, and user experience in mind.

If you're interested in the implementation, check out the repository on GitHub.
