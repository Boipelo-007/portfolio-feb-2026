## Project pages in MDX

Project write-ups live in MDX and are compiled into individual routes with Contentlayer. The format keeps the content easy to revise while supporting code samples, lists, and technical details.

## A small application stack

The site uses Next.js App Router, React, and TypeScript. Tailwind CSS handles the interface styling, and Framer Motion powers the interactive project cards.

Page-view counts use Redis when configured. Vercel Analytics provides an additional view into site traffic. The visual direction stays dark and restrained so the project work remains the focus.
