First Portfolio is the first website I built to introduce myself as a developer and document what I was learning in 2024.

The site brings a short profile, technical skills, education, project placeholder, and contact links into a single responsive experience.

## Portfolio sections

The page is organized around a focused introduction, an about section, grouped technical skills, a project case-study slot, education, and contact details.

The project section includes a placeholder for a Coding Club Website case study, with room for the project brief, screenshots, technical decisions, and live links when they become available.

## Interface and layout

The design uses a warm neutral palette, strong editorial typography, clear section labels, and a dark skills panel. The layout adapts from a large two-column hero into a stacked mobile experience.

The page also includes a sticky-feeling header state as the visitor scrolls, smooth in-page navigation, accessible landmarks, and mobile-specific layout adjustments.

## Stack and structure

The implementation is built with semantic HTML, CSS, vanilla JavaScript, and Vite. Tailwind CSS is included as a dependency for future work.

The source is split into the main page, global styles, a small page entry script, and image assets. Vite serves the application from the `src` directory and produces a static production build.

## What this project taught me

Building this portfolio gave me a first complete journey through a website's structure, visual design, responsive behavior, and deployment setup. It also made the role of source organization and maintainable styling clear as the page moved from a first draft into a reusable project.
