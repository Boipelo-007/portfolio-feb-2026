# Patel Hardware

Patel Hardware is a full-stack hardware-store web application built to explore Java servlet development and relational database integration.

The application brings customer registration, inventory browsing, search and filtering, session-based access control, and shopping-cart management into one store experience.

## A complete store flow

Customers can create an account, sign in, browse the hardware catalogue, and manage items in a cart. The application keeps cart operations tied to the signed-in customer and checks availability before quantities are updated.

## Customer accounts

Users can register with a username, email address, password, and optional contact details. The server validates required fields and email format, prevents duplicate usernames or email addresses, and stores passwords as bcrypt hashes.

## Inventory and search

The catalogue exposes item names, catalogue numbers, descriptions, prices, categories, availability, and stock quantities. Customers can browse all inventory or narrow the results through search and filters.

## Shopping cart

Authenticated customers can add available items, change quantities, remove products, review totals, and complete the checkout flow. AJAX and JSON keep inventory and cart updates responsive without requiring a full page reload.

## Technical implementation

Java Servlets handle requests, with JavaBeans-style model classes representing users and inventory items. Jackson serializes server responses into JSON, while the browser uses `fetch` and vanilla JavaScript to update the interface.

JDBC handles database access, and prepared statements are used across login, registration, inventory, and cart queries. This keeps user input separate from SQL syntax.

Maven packages the HTML, JSP, classes, and dependencies into a `patel-hardware.war` file for deployment to a Servlet-compatible container.

## Architecture

```text
Browser
  |
  | HTML / JavaScript / JSON
  v
Servlet Controllers
  |
  | JDBC
  v
MySQL
├── users
├── items
└── cart
```

## What this project taught me

This project provided hands-on experience connecting a browser interface to a Java backend without a framework. It reinforced HTTP session behavior, servlet request and response handling, SQL-backed CRUD operations, password security, JSON APIs, and WAR deployment.

It also highlighted the importance of keeping database configuration, schema naming, and connection code consistent across an application.
