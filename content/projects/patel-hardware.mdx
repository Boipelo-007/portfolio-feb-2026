# Patel Hardware

Patel Hardware is a full-stack hardware-store web application built as a practical exploration of Java servlet development and relational database integration.

The application provides customer registration and authentication, inventory browsing, search and filtering, session-based access control, and shopping-cart management.

## Project Highlights

- Built an inventory catalogue backed by MySQL and JDBC.
- Implemented registration and login workflows using Java Servlets.
- Used bcrypt for secure password hashing and verification.
- Added session-based authentication and protected account actions.
- Created dynamic inventory, search, and cart interfaces with AJAX and JSON.
- Added stock-aware cart actions and quantity management.
- Deployed as a Maven-generated WAR for Servlet-compatible containers.

## Key Features

### Customer Accounts

Users can register with a username, email address, password, and optional contact details. The server validates required fields and email format, prevents duplicate usernames or emails, and stores passwords as bcrypt hashes.

### Inventory and Search

The catalogue exposes items with names, catalogue numbers, descriptions, prices, categories, availability, and stock quantities. Users can browse the complete inventory or search and filter records from the interface.

### Shopping Cart

Authenticated customers can add available items to a cart, change quantities, remove products, review totals, and complete a checkout flow. Cart operations are persisted in MySQL and associated with the signed-in user's session.

## Technical Implementation

The project uses Java Servlets for request handling and JavaBeans-style model classes for users and inventory items. Jackson serializes server responses into JSON, while the browser uses `fetch` requests and vanilla JavaScript to update the interface.

JDBC handles database access. Prepared statements are used for login, registration, inventory, and cart queries, helping separate user input from SQL syntax.

The Maven configuration packages HTML, JSP, classes, and dependencies into a `patel-hardware.war` deployable.

## Architecture

```text
Browser
  |
  | HTML / JavaScript / JSON
  v
Servlet Controllers
  |
  | JDBC
  v
MySQL
├── users
├── items
└── cart
```

## Challenges and Learning Outcomes

This project provided hands-on experience connecting a browser interface to a Java backend without a framework. It reinforced HTTP session behavior, servlet request/response handling, SQL-backed CRUD operations, password security, JSON APIs, and WAR deployment.

It also demonstrated the importance of keeping database configuration, schema naming, and connection code consistent across an application.
